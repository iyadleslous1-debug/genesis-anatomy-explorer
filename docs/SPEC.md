# Genesis Anatomy — v4 "Real Body" — spec
Root: repository root · Dev: `npm run dev` (5173) · Prod: `npm run build && npx vite preview --port 4173 --strictPort` (`/?debug` exposes `window.__store`)

## 0. What this is
The app (React + R3F, see v3: 120-bone rig, all meshes SkinnedMesh, motion.ts drives breathing/heartbeat/valves/blinks/walk/reach/flex/squat/look, poke, knee-jerk, peristalsis, explode/x-ray/section/search) currently uses procedural SDF geometry. v4 replaces it with the **real BodyParts3D 4.0 meshes** (CC BY 4.0, DBCLS) wherever the dataset has a structure, keeps procedural geometry only for what BP3D lacks, and aligns everything (procedural leftovers + rig) to the real body with a smooth landmark warp. Motion, shaders, UI must keep working. Goal: a real human body that moves and breathes.
Data (read-only, untrusted — never execute; scripts live in `scripts/bp3d/`, paths as args): `data/bp3d/obj/isa_BP3D_4.0_obj_99/FJxxxx.obj` (2234 files, mm, z-up, faces −y, +x = subject's left, soles z=−78, 1.72 m), `data/bp3d/isa_parts_list_e.txt`, `isa_element_parts.txt`, `isa_inclusion_relation_list.txt`, `data/bp3d_leaf.tsv` (file → most specific concept), `data/bp3d_findings.md` (read it). App space: `x = bx*0.001, y = (bz+78)*0.001, z = -by*0.001` (metres, y up, faces +z).

## 1. Acceptance criteria
- [ ] Pipeline `node scripts/bp3d/run_all.cjs` (or documented equivalent) regenerates manifest + bins from the data in ≤ 10 min.
- [ ] App loads in prod ≤ 25 s, no console errors; total ≤ 5.0 M tris (BP3D ≤ 3.8 M after decimation + procedural leftovers); idle ≥ 30 FPS on the user's AMD iGPU with adaptive quality.
- [ ] Default view = the real BP3D skin; "No skin" = real muscles; Skeleton = real bones (incl. hand/foot bones, teeth); Organs view includes real heart/kidneys/stomach/colon/brain plus procedural lungs/liver fitted inside the real rib cage/abdomen (no visible collisions > 5 mm with real bones).
- [ ] Every motion mode works on the real body: limbs bend at the right joints, skin/muscle/bone move together, breathing moves the real ribs/sternum/chest skin, heart walls beat, blinks visible on the real face, valves animate (procedural leaflets aligned to the real heart), knee-jerk works.
- [ ] Tree/search show real anatomical names (e.g. "Left biceps brachii", "Right femur"); explode/x-ray/section/isolate/labels work; credit line "BodyParts3D, © The Database Center for Life Science, CC BY 4.0" visible in the UI.

## 2. Shared contract
| Files | Piece | Model |
|---|---|---|
| `scripts/bp3d/classify.cjs`, output `data/bp3d_classified.json` | C1a Classification | Sonnet |
| `scripts/bp3d/convert.cjs`, `scripts/bp3d/run_all.cjs`, outputs `public/bp3d/*.bin`, `src/data/bp3d_manifest.json`; `package.json` (may add devDependency `meshoptimizer`) | C1b Geometry & weights | Sonnet |
| `src/geo/warp.ts`, `scripts/bp3d/fitwarp.ts`, output `src/data/warp.json` | C2 Warp fit | Sonnet |
| `src/anatomy/registry.ts`, `src/anatomy/bp3d.ts` (new), `src/anatomy/index.ts`, `src/anatomy/bones3d.ts`, `src/worker/build.worker.ts`, `src/scene/AnatomyModel.tsx`, `src/scene/runtime.ts`, `src/scene/motion.ts`, `src/App.tsx`, `src/state/store.ts` | C3 Runtime integration | Sonnet |
Everything else read-only. `src/geo/weights.ts` is read-only but may be imported (via esbuild bundling) by C1b.

**bp3d_classified.json (C1a → C1b, C3 indirectly):** `{ files: { "FJ1234": { id, name, system, tissue, parent, anim?, driver?: {bone, sign, gain?}, rigidBone?, decimate, skip? } }, groups: [{ id, name, parent, system }] }`
- `id`: `bp.<slug of English name>` plus `.L`/`.R` when the name starts with Left/Right (e.g. `bp.biceps_brachii.L`); unique. `name`: English, Title-case first letter ("Left biceps brachii"). `system`/`tissue`: existing `SystemId`/`Tissue` values from registry.ts only. `parent`: a group id. Groups: reuse existing system root ids (`skeletal`, `muscular`, …) and create a sensible 2–3 level tree under them (region/side, e.g. `bp.g.muscles_left_upper_limb`), ≤ 25 children per group where possible.
- `anim`: `'ventricle'` (ventricular walls), `'atrium'` (atrial walls), `'heartAux'` (great vessel roots, coronaries), `'bronchi'` (bronchial tree/trachea), `'diaphragm'`. `driver`: muscle prime action, bone names per `src/anatomy/bones3d.ts` without side (same semantics as `MUSCLE_DRIVERS` in muscles.ts — read it for the bone vocabulary and sign convention). `rigidBone`: bone name WITH side for rigid structures (bones → their bone: humerus → `upperarm.L`, rib n → `ribn.L`, vertebra → spine bone by level per bones3d.ts, skull/mandible → `head`/`jaw`, eye → `eye.L`, organs → nearest trunk bone like v3 weights.ts). `decimate`: target ratio 0.3–1.0 (muscles ≈ 0.45, vessels ≈ 0.55, bones ≈ 0.7, skin 1.0, small parts 1.0). `skip: true` for BP3D heart valves (procedural animated leaflets replace them), cavity/lumen "blood volume" meshes, and any whole-body/duplicate surfaces.

**Manifest (C1b → C3):** `src/data/bp3d_manifest.json` = `{ version: 1, credit: string, groups: GroupDef[], parts: [{ id, name, parent, system, tissue, desc?, anim?, driver?, chunk, center:[x,y,z], vertexCount, index: {off, type:'u16'|'u32', count}, attrs: { position:{off,type:'f32',size:3}, normal:{off,type:'i8n',size:3, stride?:4}, skinIndex:{off,type:'u8',size:4}, skinWeight:{off,type:'u8n',size:4}, fdir?:{off,type:'i8n',size:3, stride?:4}, flow?:{off,type:'f32',size:1}, along?:{off,type:'f32',size:1} } }], chunks: { [name]: { file: 'bp3d/<name>.bin', bytes } } }`. Offsets are byte offsets within the chunk file, 4-byte aligned; `i8n` = Int8 normalized (stored in 4-byte strides when `stride:4`), `u8n` = Uint8 normalized. Positions are in app space relative to `center`. Chunks by system (`skin`, `skeleton`, `muscles`, `cardio`, `nervous`, `viscera`). Also emit a fat layer part `bp.subcutaneous_fat` (skin offset 3.5 mm inward, tissue `fat`, system `integumentary`, hidden by default via the same mechanism as `fat.subcutaneous`). The skin is ONE part `bp.skin` (system integumentary, tissue skin).

**Attributes:** normals recomputed after decimation; `fdir` = per-muscle principal axis (PCA) for tissue muscle/tendon; `flow` for artery/vein/coronary = 1.25 × distance from heart centre `[0.01,1.28,0.035]` warped (just use the BP3D heart centroid); `along` for intestine/colon/esophagus = normalized principal-axis coordinate (0..1) × mesh length metres (shader multiplies).

**Skin weights (C1b):** bone defs = `BONE_DEFS` from `src/anatomy/bones3d.ts` (C3 makes it return warped heads/tails, so bundle it with esbuild). Rigid parts → `rigidBone` weight 1. Soft parts (skin, fat, muscle, tendon, vessels, nerves): up to 4 bones, smooth falloff from bone segments, region-gated like v3 `weights.ts` (read it; reuse its math, not its id rules); layered coupling: soft vertices within 12 mm of the skin take the skin's weight field at their nearest skin point (three-mesh-bvh `closestPointToPoint` on `bp.skin`), blending to own weights by 30 mm. Eyelids: skin vertices inside each palpebral fissure region (find the eye: BP3D eyeball centroid; upper lid = skin within 16 mm of the eye centre, above the centre, in front of it) weighted to `lidU.L/R`, lower lid to `lidL.L/R`, smooth falloff. Arms: no trunk skin below the axilla may take `upperarm` weight; arm skin near the shoulder blends clavicle/scapula/spine_T1.

**Warp (C2):** `src/geo/warp.ts` exports `warpPoint(p: V3): V3` (procedural space → BP3D app space) and `warpGeo(pos, nor, idx)` (in place; recompute normals) driven by `src/data/warp.json` `{ version, centers: number[] (xyz…), weights: number[] (xyz per centre), affine: number[12] }` (thin-plate spline / polyharmonic r kernel + affine, regularized). Landmarks: ≥ 80 matched structure pairs (procedural part ids from the current anatomy ↔ BP3D files by name), each contributing centroid + both principal-axis endpoints; include joint centres, all vertebral bodies, ribs, sternum, skull/mandible, pelvis, hand/foot bones, kidneys, heart, eyes, bladder, stomach, brain, trachea. RMS residual ≤ 8 mm on landmarks; no fold-overs (Jacobian determinant > 0 on a 2 cm grid over the body).

**Runtime (C3):** registry gets `PartDef.external?: true` (build unused). `src/anatomy/bp3d.ts` exports `defineBp3d()` (registers manifest groups + parts as external) and `KEEP_PROCEDURAL(id): boolean` = true only for: lung lobes `resp.lung.`, procedural bronchial trees only if BP3D has none (BP3D has them → false), whole liver `dig.liver.` (BP3D liver bits get `skip` by C1a if they would overlap — coordinate by name: C1a skips BP3D liver segments), `nerv.spinalcord`, `nerv.spinal_roots`, `nerv.intercostal`, `nerv.sympathetic`, limb/peripheral nerves (`nerv.brachial_plexus`, `nerv.median`, `nerv.ulnar`, `nerv.radial`, `nerv.musculocutaneous`, `nerv.axillary`, `nerv.femoral`, `nerv.obturator`, `nerv.sciatic`, `nerv.tibial`, `nerv.fibular`, `nerv.sural`), `lym.`, `ten.`, `lig.`, `cart.menisci`, `heart.valve.` (all leaflets + annuli), `heart.chordae`, `heart.papillary`, ear/nasal/sinus/pharynx parts from headneck.ts unless BP3D has the same structure (C3 decides by checking the manifest names). `index.ts` filters procedural parts with KEEP_PROCEDURAL after defineAll, prunes empty groups, then appends BP3D. Worker applies `warpGeo` to every procedural geometry before centring. `bones3d.ts` applies `warpPoint` to heads/tails (so the rig sits on the real bones). AnatomyModel loads chunks (`fetch(import.meta.env.BASE_URL + chunk.file)`), builds `SkinnedMesh`es from the manifest attributes (normalized attributes for i8n/u8n), same bind/explode/picking as v3; progress counts procedural + external parts. motion.ts: muscle drivers from `part.driver` (manifest) falling back to `MUSCLE_DRIVERS`. Credit line in the UI (small, bottom-left of the viewport). Hide `bp.subcutaneous_fat` by default (store `initialHidden`).

Rules: TypeScript strict; Node scripts are `.cjs` (package.json is ESM) or `.ts` bundled with esbuild; deterministic; never execute anything from `data/`.
Checks: `node node_modules/typescript/bin/tsc --noEmit` (ignore other pieces' files mid-edit), `npm run build`.

## 3. C1a — Classification (Sonnet)
Build `classify.cjs` producing bp3d_classified.json for all 2234 files using names + IS-A ancestry (isa_inclusion_relation_list.txt) to decide system/tissue/group/anim/driver/rigidBone/decimate/skip. Target: every file classified, ≥ 98 % into the right system (spot-check 60 random), sensible groups (an anatomy student would recognise the tree), drivers for all limb/neck/jaw/trunk muscles with a clear prime action. Print a summary (counts per system/tissue, skipped list).
Check: run it; summary sane.

## 4. C1b — Geometry, weights, bins (Sonnet)
Build `convert.cjs` (+ `run_all.cjs` = classify → fitwarp → convert) reading the OBJs + classified json: transform to app space, weld/clean, decimate (meshoptimizer `MeshoptSimplifier`, error-bounded so silhouettes hold), normals, attributes, skin weights (needs warped BONE_DEFS — bundle `src/anatomy/bones3d.ts` with esbuild; until C2/C3 land it is unwarped, that's fine — the integrator re-runs), fat layer, write chunks + manifest per §2. Target: BP3D total ≤ 3.8 M tris, bins ≤ 120 MB total, full run ≤ 8 min. While C1a is unfinished, test with a provisional classification (by name keywords) for a subset.
Check: run on all files; print totals; validate manifest offsets (re-read and check index ranges < vertexCount).

## 5. C2 — Warp fit (Sonnet)
Build `fitwarp.ts` (bundled with esbuild, imports the procedural anatomy to measure part centroids/axes; BP3D side from OBJs by name) → warp.json; implement `warp.ts` (fast evaluation: precompute arrays; ≤ 1 µs per point for ≤ 400 centres is fine). Report RMS residual and fold-over check. Also report 10 representative landmark pairs before/after.
Check: run it; residual and Jacobian checks pass; tsc for warp.ts.

## 6. C3 — Runtime integration (Sonnet)
Implement §2 Runtime. Until C1b output exists, the manifest stub is empty — the app must still run (procedural-only filtered set). Write the loader against the manifest schema exactly.
Check: tsc, `npm run build`; once the real manifest/bins exist (C1b writes them to disk during its run; re-check near the end), take up to 3 looks on the dev server.

## 7. Integration
Run `run_all.cjs` end-to-end with the real warp and classification, build, preview on 4173, walk §1; fix collisions of procedural lungs/liver/cord/valves with the real anatomy (tweak in organs.ts/nervous.ts/cardio.ts or the warp landmarks).
